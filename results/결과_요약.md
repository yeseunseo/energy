# PeakShift 최종 결과 요약 (시험용 무작위 하루 60개)

## 실험 설정
- 공장: Dunke & Nickel (2025, Applied Energy) 공개 코드로 같은 공장 생성 (기계 3대, 작업 5개 · 10개, seed 고정)
- 가격: 2023년 독일 하루 전 시장 가격 12일 (논문과 동일)
- 추가한 불확실성: 처리 시간 ±20% (끝나야 드러남), 급주문 (9~17시 시간당 10%), 공장 태양광 (구미 실제 기록, 하루 전 예보로 계획)
- 날짜 12개 × 무작위 하루 5개 = 60개, 네 방식 모두 같은 하루를 겪음
- 시험용 하루(0~4번)는 방법을 다 정한 뒤 한 번만 채점 (연습용 5~9번, 학습용 100번 이후와 분리)

## 정직한 한계
- 탄소 가격의 추가 효과는 1% 안팎으로 작음 (독일 전력은 가격과 탄소가 함께 움직여, 비용만 줄여도 탄소가 이미 줄어 있음)
- 학습 기반 형세 판단은 이 규모에서 효과 없음 (시뮬레이션이 이미 빨라서) → 본 방법에서 제외
- 논문 결과 숫자와의 직접 비교가 아니라, 같은 공장을 우리 시뮬레이터에서 같은 조건으로 비교한 결과

## ④ 한국 적용 (같은 논문 공장, 1단위 = 30kW, 시험용 무작위 하루)
설정: 산업용(을) 고압A 선택Ⅱ 2026 개편 요금 (3~10월 15~21시 최대부하, 11~2월 기존 시간대), 기본요금 8,320원/kW (7·8·9·12·1·2월 12개월 유지), 기준치 = 그날 기존 운영의 최대 전력, 정규 08~17시 + 연장 블록 (가산 50%, 22시 이후 야간 50% 추가), 시급 18,635원, 구미 태양광 150kWp

| 상황 | 완료율 (A / B / C / D) | PeakShift 작업당 총비용 절감 (중앙값, 우위 일수, p) |
| --- | --- | --- |
| 평일 · 작업 5개 (60일) | 91.1 / 88.6 / 84.6 / **94.0**% | 기존 −15.8% (48/60, p<0.001) · 논문 −5.4% (44/60, p<0.001) · 매번 −1.3% (38/60, p=0.007) |
| 평일 · 작업 10개 (60일) | 94.0 / 80.5 / 80.5 / **96.2**% | 기존 −1.0% (54/60, p<0.001) · 논문 −13.1% (57/60, p<0.001) · 매번 −10.0% (54/60, p<0.001) |
| 봄·가을 토요일 + 플러스DR · 작업 5개 (25일) | 87.4 / 88.1 / – / **94.0**% | 기존 −4.1% (21/25, p=0.001) · 논문 −0.4% (20/25, p=0.011) |

- 기존 운영은 기본요금 기준치를 넘겨 하루 평균 래칫 45만 원 (작업 5개). PeakShift는 래칫 27.7만 원으로 39% 감소
- 바쁜 공장(작업 10개)에서 가격을 보는 다른 방식들은 작업을 약 20% 놓침. PeakShift는 96.2% 완료
- 토요일 이동: PeakShift 기준 작업당 총비용 평일 22.7만 원 vs 토요일 35.8만 원. 플러스DR로 전력량 요금은 약 29% 줄지만 연장 수당이 더 커서, 이 공장(전기 비중이 낮은 가공 공장)은 하루를 통째로 옮기면 손해 → 전력 비중이 큰 공정에서만 이득
